# Study Buddy

##  Intro
A web-based study management and productivity platform designed to help students organize tasks, improve focus, collaborate with classmates, and build productive study habits.

---

##  Description
Study Buddy is a MERN stack application built to support students in managing their academic life more effectively. It combines task management, productivity tools, collaboration features, note-taking, habit tracking, and engagement systems into a single platform.

The goal of Study Buddy is to reduce missed deadlines, improve time management, encourage consistency, and create a collaborative study environment.

###  What you can do:
- Create, edit, and manage study tasks
- Track assignments using a monthly calendar
- Set deadlines with reminders
- Use a built-in Pomodoro timer
- Monitor study habits and streaks
- Visualize study progress through charts and statistics
- Create and manage personal notes
- Restore previous versions of notes
- Upload files and images to notes
- Mark important notes as favourites
- Create study groups and collaborate with classmates
- Share files within group chats
- Receive motivational quotes
- Explore study break suggestions
- Play a daily Wordle game during breaks
- Earn achievement badges for completing goals
- Track missed tasks and productivity trends
- Submit feedback to administrators
- Receive academic assistance through an AI chatbot
